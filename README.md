# 4H Generic 1.0.0 — Android preview

One app, your family's own name. Choose a title on first open; tap, double-tap or hold it to edit later, or use Settings → Edit title & subtitle. The Android launcher label stays **4H Generic**.

- Starts empty, with your own record year and optional member, farm subtitle and fair information.
- Cattle, sheep, goats, chickens, rabbits and custom animal types, with stable identity across years and backups.
- Retains feeding, actual-date weights/charts/goals, saved feed prices, separate hay and explicit sharing, costs, stories/media, appearance, private documents, existing exports/QR, reminders and backups from the native Android foundation.
- Independent package, signing key, storage and update channel. R-C Acres can remain installed; its backups are not silently imported.

Download **4H-Generic-1.0.0.apk**, open it on Android 8 or newer and follow Android's installation confirmation. If asked, allow installation from the browser or Files app used to open it. No GitHub login is needed. For future updates, save a backup in Settings, then use Settings → Update app; records and appearance remain in this app's own storage. Do not uninstall to update.

Verified with JVM tests and native API-35 emulator checks. Physical-phone camera, codecs, notification timing/Doze, offline speech and child usability still need acceptance on the chosen phone. This is an independently signed development preview. Public story exports do not include hosting; public-data adapters, official form autofill and local fair eligibility verification remain unfinished. No medical or species-specific feeding advice is introduced.

Package: `com.fourhgeneric.android` · version: `1.0.0` · version code: `2`. The attached `update.json` provides the APK size and SHA-256. Source, signing keys and family records are not published here.
